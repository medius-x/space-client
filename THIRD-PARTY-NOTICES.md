docker images below (`docker save` archives, pinned by digest in
`electron/provisioning/files/images/manifest.json`). The license texts live in
[`licenses/`](licenses/) and ship with the installer under `resources/licenses/`.
The base OS layers inside each image (Debian/Ubuntu packages) carry their own
licenses from their respective upstream distributions.

For the copyleft components (janus, minio, the OpenJDK runtime) the complete
corresponding source code is publicly available at the upstream repositories
linked above; the digest in `manifest.json` identifies the exact version this
distribution was built from. The source offer: build sources from the pinned
digests' tags as published upstream.

The `oak-server.jar` attached to the oak-server releases is our own code plus
permissively-licensed Maven dependencies (Spring Boot ecosystem — Apache-2.0 /
EPL-2.0; jjwt — Apache-2.0; PostgreSQL JDBC — BSD-2-Clause; MinIO SDK —
Apache-2.0); their notices ship inside the respective JARs.

Electron/Chromium attribution is generated by electron-builder automatically
(`LICENSE.electron.txt`, `LICENSES.chromium.html` inside the installed app).
