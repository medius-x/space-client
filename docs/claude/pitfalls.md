# Грабли, уже пойманные здесь (space-client)

Уроки из пойманных багов — не воспроизводить. Формат: **правило + почему + фикс**.

- **StrictMode-мина в unmount-эффектax:** главный маршрут рендерится под `<StrictMode>` — в dev каждый mount-эффект прогоняется дважды (эффект → ВСЕ cleanup'и → эффект). Unmount-cleanup, откатывающий состояние, которое sibling-эффект с фингерпринт-защитой повторно НЕ применит (после cleanup'а фингерпринт уже совпадает → SKIP), молча убивает это состояние. Прецедент: попап шара вечно ждал видео — target хранился, unmount-дроп модалки чистил его через 27 мс, повторный прогон скипался. Правило: дропы внешнего состояния (IPC/retarget) живут в RUNTIME на явных путях вызова, не в React-lifecycle; диагностика таких гонок — по space.log (таймстемпы UTC!).
- **updateRole шлёт `name` ТОЛЬКО при реальном изменении** (иначе `null` = не трогать, partial-PATCH). Сервер валидирует имя роли `[\p{L}\p{N}_-]{1,32}` — буквы ЛЮБОГО алфавита (запрет кириллицы снят — юзер-решение), цифры, `_`, `-`; пробел/пунктуация — 400. Tradeoff: @-упоминания (`@token` ASCII-grammar) нечатаемую роль не матчат — остаётся текстом. 400 от `ResponseStatusException` В ЛОГ СЕРВЕРА НЕ ПИШЕТСЯ — «лог чистый» ≠ «запрос не дошёл». Дефолт новых ролей — «New-role».
- **Инлайновый `<svg>` в корне App сдвигает весь layout вниз:** даже `width=0 height=0` инлайновый svg открывает строку-бокс (~20px) ПЕРЕД `#app` — низ окна (композер/user-bar) уезжал за обрез. SVG-defs в App обязан нести `position: absolute` (вне потока).
- **«UI crashed: Maximum update depth exceeded»:** getSnapshot, собирающий литеральный объект на каждый вызов (или селектор с filter/map), РВАНУЛ useSyncExternalStore в бесконечный ре-рендер — контракт: селектор возвращает ТОЖДЕСТВЕННУЮ ссылку, пока стор не мутировал. Сеттеры всех сторов пересоздают снапшот-объект; производные массивы (filter/sort) — ТОЛЬКО в useMemo компонента, никогда в селекторе.
- **NUL-литералы в исходниках:** не писать `"\u0000"` в JS/TS-строках (коллапсируется в реальный байт, grep считает файл бинарным) — использовать `String.fromCharCode(0)`.
- Строгий TS 5.9: типизированные массивы дженеричны над буфером — `Float32Array<ArrayBuffer>` для `getFloatTimeDomainData`.
- STOMP: heartbeat-EOL может приклеиться к началу кадра в одном WS-сообщении — парсер стриппает ведущие пустые строки.
- **Удалённые WebRTC-треки молчат через `createMediaStreamSource`** (цепи строились, треки live, тишина; локальные треки при этом работают). Рабочий путь: скрытый `<audio srcObject=…>` + `createMediaElementSource` — граф (гейны, метры, стерео-сплиттер) питается от него. Локальный мик — по-прежнему `createMediaStreamSource` (анализ без плейаута).
- **`splitter.connect(gain)` несёт только ЛЕВЫЙ канал** — стерео-микс в гейн надо пускать напрямую `source.connect(gain)`, сплиттер оставлять параллельным тапом.
- **Отрывать DOM-глобали от ресивера нельзя:** `globalThis.fetch` без `.bind(globalThis)` в Chromium кидает `Illegal invocation` (node-fetch — нет, поэтому фейки в тестах этого не видят). То же потенциально касается других window-методов.
