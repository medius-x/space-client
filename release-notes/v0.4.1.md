## A much smaller installer

SPACE now ships in two builds:

- **SPACE Setup** (~135 MB) — the standard download, five times smaller than
  before. The heavy server stack is no longer bundled with it: when you set up
  a server, the machine downloads the OAK stack from GitHub itself — and if it
  cannot reach GitHub, SPACE relays the missing pieces through your computer.
  The setup flow itself looks and works exactly the same.
- **SPACE Full Bundled Setup** (~735 MB) — the self-sufficient variant for
  provisioning servers when GitHub and Docker registries are unreachable: it
  carries the entire server kit inside the installer (the network between
  your computer and the server machine is still required).

Each build updates within its own channel — a light install stays light, a
full-bundled install stays full-bundled. Updating from 0.3.x moves your
installation to the light build: the update frees about 600 MB of disk space,
and future provisioning fetches the stack over the network as described above.

## Faster server migration

The **Migrate** button now transfers your backup directly between the old and
the new server whenever the two can reach each other — authorized by a
one-shot token that expires in two hours and verified by a cryptographic
digest. Your computer only coordinates; the archive no longer travels through
your home connection twice. When a direct transfer is not possible, the
previous route-through-your-computer flow is used, now with digest
verification too.

## Fixes and polish

- Automatic login at the end of server setup could fail when a background
  session happened to be reconnecting at that moment — fixed.
- The update banner is tidier: once a new version is downloaded, a persistent
  "restart to install" offer with a single **Restart now** action appears, and
  restarting during a live call asks for confirmation first.
